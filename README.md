# Salamedia (سلاميديا)

An Arabic-first social network from Salamiyah: posts, short vertical reels, follows, and real-time public, private and group chats.

- `api/` is the NestJS 11 + Prisma 6 + PostgreSQL backend (port 4000, Swagger at `/docs`).
- `web/` is the Next.js 15 App Router frontend (port 3000).

See `CLAUDE.md` for the architecture agreement. Setup and run instructions arrive in Phase 14.
